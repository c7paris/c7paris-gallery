# C7 Paris Gallery

Public gallery page with a private `/admin` editor using Decap CMS and Netlify Identity.

## Files

- `index.html` — public gallery
- `admin/index.html` — private admin page
- `admin/config.yml` — CMS settings
- `content/gallery.json` — gallery content
- `images/uploads/` — uploaded media

## After deploying on Netlify

1. Enable Identity.
2. Set registration to invite-only.
3. Enable Git Gateway.
4. Invite yourself as a user.
5. Visit `/admin`.
6. Log in and edit the Gallery.
